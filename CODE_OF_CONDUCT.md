# Code of Conduct

## Our standard

We want a welcoming, technically rigorous community. Participate with respect,
assume good faith, explain disagreements clearly, and keep feedback focused on
the work rather than the person.

## Expected behavior

- Be constructive and patient.
- Respect different backgrounds, experience levels, and viewpoints.
- Protect privacy: do not publish credentials, private transcripts, or personal
  data.
- Prefer evidence, reproducible tests, and clear review comments.
- Report security concerns privately as described in [SECURITY.md](SECURITY.md).

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, publishing
private data, deliberate disruption, and attempts to bypass repository safety
controls are not acceptable.

## Enforcement

Maintainers may remove comments, close contributions, or restrict participation
when behavior violates this code. Report concerns privately through the
security contact described in [SECURITY.md](SECURITY.md), including links and
context where safe to do so.
