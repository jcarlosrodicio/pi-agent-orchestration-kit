# v0.2.3 - Bounded remote Open Design transport

This release hardens the remote Open Design bridge against stalled or
unbounded HTTP and SSE responses.

## Highlights

- Apply connection, total, and idle-read timeouts to remote requests.
- Bound JSON response bodies, SSE bytes, event counts, and captured output.
- Keep remote error messages generic so response bodies are not returned to Pi.

## Installation or upgrade

Pin the public harness to this release:

```bash
pi install git:github.com/jcarlosrodicio/pi-agent-orchestration-kit@v0.2.3
```

For an existing checkout, run `npm run check:release` before installing the
updated package.

## Migration

No migration is required. The remote bridge keeps the existing
`OPEN_DESIGN_URL` contract and only rejects responses that exceed its safety
budgets or remain idle beyond the configured limits.

## Validation performed

The public package check, full unit test suite, oversized JSON/SSE tests,
stalled-connection test, and production dependency audit pass for this
release.

## Public safety boundary

The public release excludes Pi settings, model provider configuration,
credentials, authentication files, MCP state, transcripts, caches, absolute
machine paths, and runtime evidence.
