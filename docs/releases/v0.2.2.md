# v0.2.2 - Interactive Pi model switching

This release adds a standalone `pi-switch` TUI for selecting Pi's configured
model routes without sharing OpenCode's provider catalog.

## Highlights

- Select Pi's default model or one or more agent overrides interactively.
- Read the available model catalog from Pi's own `pi --list-models` command.
- Persist native Pi settings while keeping providers, credentials, and runtime state local.

## Installation or upgrade

Pin the public harness to this release:

```bash
pi install git:github.com/jcarlosrodicio/pi-agent-orchestration-kit@v0.2.2
```

For an existing checkout, run `npm run check:release` before installing the
updated package.

## Migration

No migration is required. Existing Pi settings remain valid; `pi-switch` adds
an interactive way to edit the native default and agent override fields.

## Validation performed

The public package check, unit tests, and bounded `pi-switch` terminal smoke
pass for this release.

## Public safety boundary

The public release excludes Pi settings, model provider configuration,
credentials, authentication files, MCP state, transcripts, caches, absolute
machine paths, and runtime evidence. The catalog is resolved locally by Pi.
